## Week 1: Title Screen & World Intro

**Module topic:** `print()`, comments, Rich markup

### What You'll Build

A colorful title screen that introduces the game world. When you run
`python game.py`, you should see:
- A bold green title banner
- A narrative paragraph setting the scene (you've spawned in a forest)
- A biome description box
- A credits line

### Code to Add

Copy this into `game.py`, replacing everything that's there:

```python
# =============================================================================
# Block Builder — A Survival Craft Adventure
# =============================================================================
# Week 1: Title Screen & World Intro
# Concepts used: print(), comments, Rich import
# =============================================================================

# Rich gives us colorful terminal output
from rich import print

# Game title — bold green like Minecraft's color palette
print("=" * 50)
print("[bold green]        BLOCK BUILDER[/bold green]")
print("     A Survival Craft Adventure")
print("=" * 50)

# Set the scene — you've spawned into a new world
print()
print("[green]You open your eyes.[/green] Sunlight filters through")
print("the leaves of a dense forest. You have nothing but")
print("your bare hands. Night will fall soon, and with it")
print("come creatures that hunt in the dark.")
print()
print("To survive, you'll need to [bold]gather resources[/bold],")
print("[bold]craft tools[/bold], and [bold]build shelter[/bold]")
print("before the sun goes down.")

# Describe the starting biome
print()
print("-" * 50)
print("[bold cyan]Biome: Forest[/bold cyan]")
print("Tall oak trees surround you. A river flows nearby.")
print("You can see a mountain range in the distance.")
print("The ground is covered in grass and loose stones.")
print("-" * 50)

# Credits
print()
print("[dim]A CS 1400 Project[/dim]")
print()
```

### Make It Yours

After you have the base code working, personalize it:
- Change the biome description (desert? tundra? mushroom forest?)
- Add more narrative lines to the intro
- Add your name to the credits
- Experiment with Rich markup: `[bold]`, `[red]`, `[dim]`, `[underline]`

Run: `pytest tests/test_week01.py -v`

### Tips

- Run `pip install rich` if you get an import error
- Run the game after every few lines to catch mistakes early
- Comments explain **why**, not **what** — `# Set the scene` is better than `# print stuff`
